# Salesforce Developer Virtual Internship – Day 4

## 📌 Project Title

**Lightning Web Components (LWC) – Placement Management System**

---

## 📖 Project Overview

This project was developed as part of the **Salesforce Developer Virtual Internship – Day 4**. The objective was to learn the fundamentals of **Lightning Web Components (LWC)** by creating a simple Placement Management System. The project demonstrates component creation, data binding, event handling, and Lightning App Builder deployment.

---

## 🎯 Objectives

- Understand Lightning Web Components architecture.
- Create and deploy an LWC.
- Learn data binding using JavaScript variables.
- Implement event handling using buttons.
- Build a simple Placement Management Dashboard.
- Gain hands-on experience with Lightning App Builder.
